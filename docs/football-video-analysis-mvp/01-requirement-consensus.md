## 当前任务

为 DJI Action5 固定机位拍摄的 5 人制足球比赛视频，设计一套可复用的命令行 MVP 分析流程。第一阶段以“能稳定产出有用赛后报告”为目标，而不是追求完全自动、完全精确的职业级数据系统。

- 文件大小: 约 3.4GB
- 拍摄方式: 球场中线靠左位置，约 4 米高固定支架拍摄
- 画面条件: 基本能看清全场，足球基本清晰，球场边线、中线、禁区/罚球区线、球门位置清楚可见
- 当前本机环境限制: 尚未安装 `ffprobe` 和 Python `cv2`，第一版工具需要包含依赖初始化和视频元数据读取步骤

## 目标输出

第一版工具需要输出:

- 每名红队球员评分，按业余 5 人制通用评价口径
- 技术统计: 射门、传球、抢断
- 跑位/战术复盘: 站位纪律、压迫强度、无球跑动
- 训练改进建议
- Markdown 报告
- CSV 数据表
- HTML 报告
- 关键片段时间戳

## 自动化边界

用户不希望进行繁重人工标注。允许的人工输入和校验仅限:

- 赛前或赛后录入球员身份、号码、外观特征和角色
- 固定机位下做一次球场映射校准，选择场线关键点
- 当前片段或完整比赛录入换人时间
- 自动分析后快速校验关键事件和身份串号问题

不接受的方式:

- 逐帧标注球员、球、传球和射门
- 每场都进行大量手工事件录入
- 把报告主要建立在人工观看主观评价上

## MVP 成功标准

MVP 的成功不是“每个事件都像职业数据公司一样精确”，而是:

1. 对固定机位视频可重复运行。
2. 能输出红队 5 人的可读赛后报告。
3. 技术统计和评分能解释其依据。
4. 报告能指出每名球员 1 到 3 条可训练改进建议。
5. 对低置信度事件有标记，不把不确定推断写成事实。
6. 人工校验量控制在每场约 5 到 15 分钟。
7. 后续增加完整比赛、换人、更多球员时不需要重写主流程。

## 关键风险

- 足球体积小、速度快，即使“肉眼清晰”，模型仍可能漏检，需要球轨迹平滑和候选事件校验。
- 球员遮挡会造成追踪 ID 串号，需要外观特征、位置约束和少量校验兜底。
- 站位纪律、压迫强度、无球跑动属于解释型指标，第一版应给出量化依据和置信度，避免过度拟人化解读。
- 当前没有视频时长、帧率、分辨率元数据，需要环境装好后先做视频探测。
