# 与 B 级青训教练的对话备稿

> 日期:2026-05-11
> 对象:重点城市大区体育局青训系统下的 B 级教练
> 目的:理解他的教学理念和方法,识别系统能"放大"他的具体场景,**不夸大、不替代他的判断**
> 时长建议:60 分钟,前 25 分钟听 + 演示 15 分钟 + 共同设计 15 分钟 + 留尾 5 分钟

---

## 1. 心态前提

带去的不是产品,是**他执教过程中"原本要人工做、现在可以系统替他做"的环节列表**。

三条铁律:

1. **他是专家,你不是**。任何 "这样可以让训练更科学" 的话都不要主动说;系统的价值是把他原本的科学性可量化,不是定义科学性。
2. **数据不是评判,是描述**。绝对不说"系统给球员打 7.5 分代表他能力中等";应说"这名球员本场跑动距离 3.4 km,占场地总时间 60% 在进攻三区"。
3. **承认不确定性**。技术候选(传/射/抢断)目前是低置信启发式;球检测召回在一场已标定金标上是 83%,泛化到新场地需要再标。不藏起来。

---

## 2. 见面前的开场问题(用来真正听)

这 8-10 个问题决定后面所有沟通的方向。不要急着展示功能。

**关于他自己**

1. 您带哪个年龄段、训练周期(每周几次、每次多久、一年多少场)?
2. 您带这批球员多久了?他们的水平梯度是什么?
3. 您评 A 级的计划路径是什么?目前在评的项目还差哪些证明材料?

**关于他的教学理念**

4. 如果用 2-3 句话总结您的训练核心理念,您会怎么说?
5. 您觉得现在主流青训里哪一两个做法是您不太认同的?为什么?
6. 一节训练课结束后,您脑子里最常浮现的 3 个问题是什么?

**关于现有工具和痛点**

7. 您拍录像吗?用什么设备?录像后怎么处理?多久看一次?
8. 您给一个球员做长期反馈时,目前依据是什么?(凭印象?笔记?录像回看?)
9. 上一次评级答辩 / 公开课 / 比武,您最希望但当时没有的材料是什么?
10. 您和家长沟通孩子表现时,最怕被问到的问题是什么?

**关于他对数据的态度**

11. 如果您看到系统给出"球员 A 本场跑动比上场多了 0.8 km",您会信任到什么程度?哪些信号您会觉得"数据不可信"?

## 3. 当下系统具体能给他什么(诚实清单)

每一条都标了:**他带来的部分** + **系统放大的部分** + **真实输出形态** + **当前限制**。

### 3.1 训练效果的客观证据(评级 / 公开课最稀缺的材料)

| | 内容 |
|---|---|
| 他带来的 | 一项明确的训练目标(例如"在 4 周内提升前场压迫强度") |
| 系统放大 | 训练前一场 + 训练后一场比赛,自动产出 `pressing_pct` 等 6 个相关指标的对比 |
| 输出形态 | 一张前后两场的指标对比表;一份带具体球员名字的变化清单 |
| 当前限制 | 比赛环境(机位、天气、对手强度)会引入噪声;变化幅度小于 15% 时可能是统计噪声而非教学效果 |
| 对他的真实价值 | 公开课答辩时,有一张"我们的训练目标 → 这是赛场上发生的变化"的对应证据 |

### 3.2 球员个体的纵向发展轨迹(因材施教理念的落地)

| | 内容 |
|---|---|
| 他带来的 | 每个球员的长期培养重点(例如"小张需要加强无球跑动") |
| 系统放大 | 每场比赛产出 per-player 多维指标,跨场可聚合成轨迹(待开发但工作量小) |
| 输出形态 | 一名球员的"3 个月、N 场比赛"的折线图,聚焦教练关心的 2-3 个指标 |
| 当前限制 | 跨场球员身份要靠球衣号码 + 名字一致;不能自动识别球员,目前每场需要 5-10 分钟人工绑定 |
| 对他的真实价值 | 家长会有可视化进展;评级答辩有"我带过的球员真实进步了"的硬证据;选材时有客观抓手 |

### 3.3 比赛复盘的素材效率(教练观察理念)

| | 内容 |
|---|---|
| 他带来的 | 复盘要讲什么瞬间的判断 |
| 系统放大 | 自动标出 20-30 个候选事件(高速跑、压迫、进攻三区跑动)的时间戳 |
| 输出形态 | 一份按时间排序的"候选时刻列表",带球员姓名 + 事件类型 + 大致原因 |
| 当前限制 | 候选 ≠ 真实事件;教练需要快速判定"这个时刻是不是我要讲的";传球/射门/抢断目前可信度更低 |
| 对他的真实价值 | 节省"从 30 分钟视频里找 5 个关键瞬间"的时间(原本 30 分钟,现在 5 分钟) |

### 3.4 球员档案(青训系统下的输送 / 输出价值)

| | 内容 |
|---|---|
| 他带来的 | 对每名球员的整体判断和成长定位 |
| 系统放大 | 每名球员每场比赛的客观指标存档;按教练编辑后可导出成"球员档案" |
| 输出形态 | 标准化的球员发展报告(可对接体育局格式) |
| 当前限制 | 报告导出模板需要按目标场景定制(评级答辩 vs 体校招生 vs 选拔队推荐);目前没有现成模板,需要他告诉我们应该是什么样 |
| 对他的真实价值 | 球员升学、转会、选拔时有客观材料;长期培养的"作品集"建立 |

### 3.5 家长沟通的客观语言

| | 内容 |
|---|---|
| 他带来的 | 沟通的判断和分寸 |
| 系统放大 | 提供本场比赛的中立描述性数据 |
| 输出形态 | 一张简短的"本场表现卡":跑动 + 站位 + 主动参与 + 趋势 |
| 当前限制 | 数据不会自己产生价值——教练需要把"小李进攻三区时间提升 11%"翻译成"小李这周对进攻意识有了主动追求" |
| 对他的真实价值 | 家长不再追问"教练您怎么知道我家孩子在进步";不再依赖"凭感觉" |

### 3.6 体能 / 训练负荷管理(可选)

| | 内容 |
|---|---|
| 他带来的 | 训练负荷与休息的安排判断 |
| 系统放大 | 每场比赛的跑动距离 / 高速跑次数,可以做趋势监测 |
| 输出形态 | 球员跨场体能轨迹 |
| 当前限制 | 比赛跑动 ≠ 训练负荷;系统不知道训练实际强度;只能作为"赛场表现"维度的参考 |
| 对他的真实价值 | 较粗的二级辅助信号,可作为"是否需要轮休"的输入之一 |

## 4. 演示环节的剧本(15 分钟,基于他在问题 1-11 的回答动态调整)

**不要演示一切**。挑 1-2 个最贴他痛点的场景做完整演示。

### 备用 A:训练效果证明

1. 打开一场真实比赛(中青赛_1),展示 `player_metrics.csv` 里 5 个球员的数据
2. 说明每列含义,只挑他关心的 3-4 列
3. 假设"如果上一场比赛在 4 周前,这场就是训练后",指出可对比的 3 个维度
4. **不要解释数据意义**,让他来解释 "您觉得这数字代表什么?"
5. 听他怎么解读,记录他的"翻译方式"——这是后续报告语言的最佳参考

### 备用 B:复盘片段挑选

1. 打开 `key_timestamps.csv`,展示 26 条候选事件
2. 选 2-3 条让他评估"是不是真正想讲的"
3. 问:如果一场比赛能自动给您 10 个最值得讲的瞬间,您选片段的工作量降低多少?
4. 现场剪 1-2 个片段(如果时间允许)

### 备用 C:球员档案模板

1. 拉一名球员(比如 JYN)的多场指标
2. 把他想看的字段筛出来
3. 问:这个孩子有哪 3 句话您会让家长看到?这 3 句话需要哪些字段支撑?
4. 这就直接定义了我们的报告模板

## 5. 共同设计环节(15 分钟)

这一段是关键——让他参与定义系统的下一步。

### 引导问题

1. 您能想象在 3 个月后您的工作里有这个工具吗?它会做什么不同?
2. 如果只能做一个功能,您选哪个?
3. 您的同行(其他 B 级 / A 级教练)如果看到这个工具,他们最可能用来做什么?
4. 您觉得这个工具如果要被体育局认可、纳入青训体系考核辅助材料,需要什么样的特征?

### 现场可承诺的事

如果他的某个具体需求是当前系统数据已经能支撑、只是没做出可视化:
- 承诺"2 周内做一个 MVP 给您看",**不要承诺生产级版本**
- 留一份带他名字的"试用版"输出

### 现场不要承诺的事

- 不承诺"系统能评估球员能力"
- 不承诺"系统能替代教练判断"
- 不承诺"系统能用在 7v7 / 11v11"(目前只验证过 5v5)
- 不承诺"和体育局对接"(没有这个能力)
- 不承诺"AI 自动生成训练计划"(LLM 可以辅助,但需要更多设计)

## 6. 系统当下能力的诚实事实卡(带去对话)

如果他问"具体能做到多准",直接念这一段:

- **球员检测**:基于 YOLO11n + ByteTrack。person 类在 5v5 业余画质下覆盖率约 100%,但同一球员的 track ID 会在密集对抗时切换,目前每场需要 5-10 分钟人工绑定身份。
- **球检测**:原生 COCO YOLO 在此画质下召回率约 0%(全是误检)。我们用项目历史人工标注的球点 fine-tune 了一个单类模型 ball_v1,在已有金标段上召回 83%、位置中位误差 0.86m。**这是单场数据;换比赛场地后会下降,需要重新评估**。
- **指标置信度**:跑动距离、站位百分比、进攻三区时间 = 高置信(High);压迫候选 = 中(Medium);传球/射门/1v1 候选 = 低或候选(Candidate)——不应作为正式统计,只作为讨论起点。
- **跨场比较**:目前 manual,后期可自动聚合。
- **训练录像分析**:目前只跑比赛流水线;训练分析需要 2-3 周适配。
- **数据稳定性**:同一场比赛多次跑流水线,数字一致;但**不同场地、不同光照、不同对手强度,数据会变化**——不能直接横向比较两个不同球队的"跑动距离 3.2 km"。

## 7. 见面后要做的 5 件事(整理备忘)

回来后立即(同一天)整理:

1. **他的核心理念是什么**(原话记录,不要总结)
2. **他最痛的 3 个场景**(具体到能定义功能的程度)
3. **他对哪个功能最感兴趣**(承诺的 MVP)
4. **他对数据的真实态度**(信任度、警惕点)
5. **下一次见面前他可以提供什么**(他的某节训练课视频?某场比赛?他的球员名单?)

---

## 8. 如果对话进展顺利,可以延伸讨论的问题

仅在前面问题都聊透、且气氛融洽时:

- **数据归属**:他的球员数据,他持有(本系统是本地工具,数据不出他设备)。这是隐私和教练职业资产的双重保障。这条对体育局体系下的教练通常很关键。
- **是否帮助同行**:他是否愿意把工具推荐给同区其他教练?如愿意,我们要考虑"多教练复用"这件事的技术形态(隔离 vs 共享)。
- **数据规范化**:如果未来要让多个教练的数据能横向对比,需要建立"标准化场地"机制——这是他可能感兴趣的、可作为 A 级评审材料的话题(标准化协议设计能力)。
- **教练员认证体系**:如果工具能产出"符合体育局 / 足协格式"的报告,在他评审时是可作为佐证材料的(他自己肯定更清楚这部分的规定)。

---

## 9. 一句话总结(开场如果他问"这是什么")

> "我们做了一个本地化的足球比赛视频分析工具,把您训练里原本要凭感觉评估的部分,变成可记录、可查阅、可作为评级答辩附件的客观数据。它不会评判球员好坏,只是把场上发生的事情精确描述出来——具体怎么用、能不能带来教学价值,这次想听您说说。"
